
# Ruhea Atelier

A fashion e-commerce website designed and developed for **Ruhea Atelier**, focused on creating a modern online shopping experience for fashion products.

## Overview

This project involved designing and developing an online fashion store with a clean, modern interface for showcasing products and providing customers with a smooth browsing and shopping experience.

## Features

* Responsive fashion e-commerce website
* Product showcase and categories
* Product detail pages
* Modern and user-friendly interface
* Mobile-responsive design
* Shopping-focused user experience
* Contact/customer inquiry functionality
* Structured navigation

## Technologies

* HTML
* CSS
* JavaScript

## My Role

Designed and developed the website from the ground up, including the website structure, user interface, responsive design, product presentation, navigation, and overall user experience.
